# AI 海龟汤主持人

一个能陪你玩「海龟汤」（情境推理）的网页：你随便问只能用「是 / 不是 / 不重要」回答的问题，AI 主持人回答；你觉得猜到了，就自己把真相讲一遍，AI 判你过没过。

判定用的是 [TypeSafe AI](https://api.typesafe.ai) 的 **JEV** 概率模型（不是让大模型「感觉一下」再吐一个是/不是），所以能拿到「是 0.82 / 不重要 0.11」这种概率分布，再由代码派生出三态答案。拿不准的时候会叫 **DeepSeek** 复核一次，两边不一致就老实回答「不确定」，而不是编一个。

**用自己的 API key。** 项目不附带任何 key —— 连 `config.py` 里都没有 key 这个字段。你在网页右上角「设置」里填自己的，它只存在你的浏览器里。

> 📌 自带的 30 道题整理自网络公开页面（知乎等），不是原创，仅作演示 —— 详见 [关于自带题库](#关于自带题库)。

## 快速开始

```bash
# 1. 依赖（需要 Python 3.11+）
pip install -r requirements.txt

# 2. 配置文件（可以跳过，全部有默认值）
#    Windows:  copy .env.example .env
#    macOS/Linux:  cp .env.example .env

# 3. 启动
uvicorn app:app --reload --port 8848
```

打开 <http://127.0.0.1:8848> —— 先看到的是**题库**，点右上角「设置」填上自己的 key，挑一道开始玩。

## 怎么填自己的 API key

**只有一种方式：在网页右上角「设置」里填。**

打开网页 → 右上角**设置** → 选 API 类型 → 粘 key → 保存。就这样。

- 填 **两把**：Jev 的（必需）和 DeepSeek 的（可选，少掉「二次复核 / 进度提示 / 通关判定」三个功能）。
- 「测试连接」会把两把都试一遍，哪把有问题直接告诉你。
- key 存在**你自己的浏览器**里（localStorage），每次请求通过请求头带给后端，**服务端不落盘、不写日志、不读 `.env`**。
  > 这一点是实测过的，不是「看代码觉得没问题」：用独一无二的哨兵字符串当 key 走完建局 / 提问 / 提示 / 通关判定，再把项目目录、`logs/` 下的回合日志、服务进程的 stdout/stderr、以及返回给浏览器的每个响应体全扫一遍，一个字符都没出现。
  >
  > 想自己复现的话，照上面那句话做一遍就行。**关键是别只 grep 源码** —— 真正容易漏的是日志和异常路径（报错信息里常常会把原始请求拼进去）。
- 换台电脑 / 换个浏览器要重新填。

### 为什么不做「.env 里配一把兜底 key」

那样最省事，但对**开源项目**是错的：谁访问到你的部署，都能不填 key 直接用，花的是你的钱。而「忘了关开关」和「.env 忘了清」这两种失误都不会报错，只会安静地烧钱。

现在服务端**没有任何 key**，所以这种事在结构上不可能发生 —— 不需要靠「分享前记得改配置」这种人为约定。

代价就是 clone 下来要手动填一次 key。

### API 类型怎么选

| 类型 | 说明 | 需要什么 |
|---|---|---|
| **OpenRouter** | 用 OpenRouter 的 key 调 JEV，不用 TypeSafe 账号 | [openrouter.ai](https://openrouter.ai) 注册充值即可，**推荐** |
| **TypeSafe 官方** | 直连 `api.typesafe.ai` | TypeSafe 账号，**且账户里要先有 credits 才允许创建 key** |

> ⚠️ **JEV 和 DeepSeek 的 key 不通用**，是两个平台。上面的 JEV key 只负责判定；二次复核、进度提示、通关判定走 DeepSeek，需要另外在 [platform.deepseek.com](https://platform.deepseek.com/api_keys) 申请一个 key（设置里的第二格）。不填也能玩，只是少这三个功能。

> 踩坑记录：TypeSafe 官网注册完就建 key 会报 *"API keys cannot be created or reactivated: this organization has no available credits"* —— 得先去 Billing 充钱。这也是推荐 OpenRouter 的原因。

## ⚠️ 分享给别人 / 部署到公网

### 不用再担心「别人花你的钱」

服务端**没有任何 key**，所以没有可被滥用的额度。每个人必须填自己的 key 才能玩 —— 这是结构上的保证，不依赖你记得改哪个开关。

### 但服务端仍然能看到别人填的 key

请求会带着对方的 key **经过你的服务端**再转发给上游。自建自用完全没问题（就你自己），但如果你的服务是给别人用的，**从技术上讲你能看到他们的 key** —— 请如实告知，别把它当卖点藏起来。

### 这些接口是裸奔的

这个项目是**按「本地自用」设计的，没有账号系统**。直接扔到公网上：

- **题库可以被人读、改、删**（`GET/PUT/DELETE /api/soups/*`）。`GET /api/soups/{id}` 会返回汤底，id 是可枚举的 8 位数字，遍历一遍就能拿到全部答案；也能把题库整个删掉或灌满。公开分享题库时请自行加鉴权，或做成只读部署。
- **一定要套 HTTPS**。key 是从浏览器发到服务端的（普通请求头），明文 HTTP 会在链路中间被看光。

### 一个「以后别踩」的坑：`game_id`

一局的凭据是**开局时记下的**（`Game.creds`），后续的提问 / 提示 / 通关判定都用它，**不是**用每次请求自己带的那把 key。

现在这样是安全的：`game_id` 是 48 位随机 hex，猜不到，也没有出现在任何 URL、日志或分享链接里。

**但如果你以后想做「分享这一局」功能**（把 `game_id` 放进链接），它会立刻变成一个真漏洞 —— 拿到链接的人可以用**开局者自己的额度**提问。真要做的话，得先给每个请求加一层「请求头的 key 必须和开局时一致」的校验。

速率限制**默认是开着的**（`RATE_LIMIT_PER_MIN=60`）：`/ask`、`/hint`、`/solve` 三个花钱的接口按「谁带的 key」计数，没带 key 才按 IP 分组。60/分钟对单人玩毫无感觉，但足以把脚本刷从上千元/天压到几十元。想关掉设 `RATE_LIMIT_PER_MIN=0`。

> 这个限流是**纵深防御**，不是必需品：就算别人拿你的部署当免费代理刷，花的也是他自己的 key。它防的是「顺手薅一下」。

### 网络：代理与超时

`JEV_PROXY` 留空**不代表直连**。留空时程序会跟随 **Windows 系统代理**（「设置 → 网络和 Internet → 代理」那个），httpx 的 `trust_env` 默认就会去读它 —— 而且**显式传 `proxy=None` 也拦不住**（实测过）。

- 需要代理才能访问 `api.typesafe.ai` / `openrouter.ai` 的网络里：**什么都不用配**，系统代理开着就能用。
- 想强制直连：设 `NO_PROXY=openrouter.ai,api.typesafe.ai`
- 想强制走某个特定的代理：把地址填进 `JEV_PROXY`（会盖过系统设置）

> 🔍 **排查**：如果提问一直卡到超时，先去 Windows 的代理设置看一眼 —— 系统代理指向一个**已经关掉的**本地端口时，表现就是「所有调用都超时」，而程序日志里什么线索都没有。（开发过程中就踩过一次：探针把靶子设成 `127.0.0.1`，等于让本地代理去连它自己所在的机器，挂得毫无道理，差点误判成代码 bug。）

### 部署：`.env` 里放什么

放的都是**非机密**的配置（默认 transport、模型名、阈值、限流）。这是**故意**的 —— 这份文件可以安全地提交、分享、贴给别人看。

```dotenv
# 部署时的环境变量（内容全都是公开信息）
JEV_TRANSPORT=openrouter
RATE_LIMIT_PER_MIN=60
SOLVE_PASS_SCORE=0.75
JEV_BOTH_MARGIN=0.20
```

⚠️ 一个容易踩的点：`load_dotenv` 是**只在 `.env` 存在时**才读它，而且 `.env` 里的项会**盖掉**同名环境变量（这是刻意的：避免机器上遗留的旧环境变量静默压过配置）。所以「半开」状态最坑 —— 要么全用 `.env`，要么完全不建。

`.gitignore` 挡的是 `.env*`（含 `.env.local` / `.env.bak` 这类备份文件），只放行 `.env.example`。不过现在 `.env` 里本来就没有机密，这层只是卫生习惯。

## 玩法

1. 在题库里挑一道题（可以搜索、按标签筛选、只看没玩过的）
2. 输入框里问问题，比如「他是自杀吗」
3. AI 主持人回答 **是 / 不是 / 不重要 / 是也不是 / 不确定**
4. 卡住了可以点**给我一点提示**（提示是渐进式的，不会一次剧透）
5. 觉得猜到了 → 点**揭示真相**，用自己的话把真相说一遍，AI 判你过没过
6. 不想猜了 → 点**揭晓汤底**

### `/` 语法：一次问多个候选

「他是自杀还是被杀」这种问题，写成：

```
他是自杀/被杀
```

斜杠分隔的候选会被当成**选择题**，AI 在候选里挑一个最可能的回答（都不像就答「不确定」，不会硬选）。最多 4 个候选。

> 为什么不做自动识别？那需要在判定前多叫一次模型先判断「这是不是选择题」，成本翻倍、延迟 +1 次往返，而延迟本来就已经偏高了。写个 `/` 是 0 成本的。

### 其它

- 进度（玩到哪、哪些玩过、标记的问题）存在浏览器本地，刷新不丢。
- **开发模式**（右上角勾选）：把每次判定的概率分布、命中的候选、走的哪条分支摊开显示，调阈值时很有用。

## 题库

自带 30 道题（`data/soup.json`）。题库界面可以增删改，也可以导入。

### 导入格式

纯文本，就两条规则：

```text
# 电梯
我走进电梯准备去上学，随着电梯的上升，我知道，我再也无法去学校了。
---
星期一早上，在妈妈的催促之下我心不在焉的走进电梯准备去学校……

# 黑猫
我杀了人，当警察带走我的时候，我看到了门口的黑猫，它一直在盯着我。
---
我经常能在楼下看到那只黑猫……
```

1. **`# 标题`** 开始一条汤（标题就是整行，别的不写也行）
2. 一条汤里**第一个** `---`（三个以上减号、**单独一行**）之前是汤面，之后是汤底

再遇到 `# 标题` 就是下一条。

- 标签**不用写**在文件里 —— 导入后没法带标签，在题库界面里加就行。
- 标题重复没关系，会被当成两条不同的题。
- 空行随便用。中文标点、引号、破折号都不用转义。
- 编号由程序分配（8 位数字，从 `00000001` 起，删掉中间的题再新增会补上那个空号），不用你写。

参考 [`data/soup.example.txt`](data/soup.example.txt)。

> ⚠️ 已知限制：汤面或汤底里不要有**单独一行以 `#` 开头**，也不要有单独一行的三个以上减号 —— 会被当成新的一条汤。中文汤里基本碰不到。

## 目录结构

```
app.py                    FastAPI 服务 + 路由
config.py                 所有可调参数与阈值（大部分决策的理由都写在注释里）
.env.example              配置模板 —— 里面**没有任何 key**，都是公开配置
data/soup.json            题库
data/soup.example.txt     导入格式示例
web/index.html            游戏界面
web/library.html          题库界面
web/store.js              两个页面共用的本地进度 + 凭据读写
soup/creds.py             请求头凭据解析（key 的唯一入口）
soup/ratelimit.py         花钱接口的令牌桶限流
soup/engine.py            一局游戏的状态机
soup/solver.py            判定（含二次复核）
soup/cascade.py           多后端级联
soup/hinter.py            渐进式提示
soup/library.py           题库导入格式解析
soup/store.py             题库读写
soup/models.py            数据模型
soup/rules.py             规则层
soup/backends/            JEV / DeepSeek 客户端
soup/nlu/                 选择题切分、意图识别
eval/                     判定质量评测脚本（可选，不参与运行）
```
